# Descripción breve para la entrega

Desarrollamos una PoC para explorar una visualización georreferenciada inspirada en los anegamientos de Tigre.
El dataset utilizado es sintético y fue creado para demostrar el flujo técnico; no representa incidentes reales.
El mapa muestra 30 puntos de ejemplo con localidad, categoría e índice artificial de 0 a 100.
Permite filtrar por localidad e intensidad, consultar cada punto y observar indicadores calculados sobre el conjunto.
Como segunda versión incorporaríamos datos oficiales verificables, límites barriales y reportes revisados.
